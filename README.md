## 📖 Overview

**CourseCraft** is a demonstration of what happens when you take **Tutor LMS** — a powerful but visually generic plugin — and rebuild its entire identity from the ground up.

Dark purple gradients. Terminal-inspired micro-interactions. Canvas particle systems. Real-time status widgets. Every page is hand-crafted with a **"cinematic learning"** philosophy: the platform should feel like a place you *want* to return to — not one you *have* to.

> ⚠️ **Demo Project Notice**  
> This is a **portfolio / sample project** built to showcase custom LMS design and front-end engineering. Content, users, and course data are for demonstration only.

## ✨ Key Features

<table>
<tr>
<td width="50%">

### 🎨 Cinematic Design System
- **Dark purple palette** — `#0A0416` base with `#A855F7` → `#F472B6` gradients
- **Glassmorphism** cards with backdrop blur
- **Terminal HUD** aesthetic — status indicators, mono fonts, scanlines
- **Micro-interactions everywhere** — magnetic buttons, glow, ripple, orbit effects
- Custom **Space Grotesk + Inter + JetBrains Mono** typography

</td>
<td width="50%">

### 🧠 Built on Tutor LMS
- **Full LMS functionality** — courses, lessons, quizzes, dashboards
- **Fully re-skinned** Tutor LMS — no more default purple/yellow
- **Dark mode forced** across dashboard, archive, single course, and checkout
- **Custom course cards** — hover lifts, gradient accents, purple stars
- **Terminal-styled enrollment flow**

</td>
</tr>
<tr>
<td width="50%">

### ⚡ Advanced Interactions
- **Command palette** (`⌘K`) for instant navigation
- **Live user data** — XP points, streak counter, notifications
- **3-theme switcher** — Purple Nova · Ocean Flux · Ember Blaze
- **Real-time widgets** — live learners, next session countdown
- **Particle newsletter** — canvas animations on email input

</td>
<td width="50%">

### 📱 Responsive & Accessible
- **Mobile-first** — every section tested at 375px, 768px, 1440px
- **Reduced-motion support** — respects `prefers-reduced-motion`
- **Keyboard accessible** — full `⌘K` palette, ARIA labels
- **Fast** — no heavy frameworks, pure CSS3 + vanilla JS
- **SEO-ready** — proper semantic HTML, meta tags, structured content

</td>
</tr>
</table>
